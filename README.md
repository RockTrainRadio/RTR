# Rock Train Radio — Player v1

Página estática gratuita para GitHub Pages, Cloudflare Pages o Vercel.

Reproduce directamente:
https://radiomas.co:8443/rocktrainradio.mp3

No hace proxy del audio y no requiere servidor propio.

### Publicación en GitHub Pages
1. Crea un repositorio público.
2. Sube `index.html`, `styles.css` y `app.js`.
3. Settings → Pages → Deploy from a branch.
4. Selecciona `main` y `/root`.
5. GitHub entregará una URL pública HTTPS.

La primera versión deja "Ahora sonando" preparado para integrar metadatos de Icecast cuando tengamos el endpoint correspondiente.
